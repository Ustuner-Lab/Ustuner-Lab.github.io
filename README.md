# Ustuner Lab website

This is a static website prepared for GitHub Pages. The home page is `index.html` and has no build step.

## Publish with GitHub Pages

1. Create or choose a GitHub repository and add these files at the repository root.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**, choose the `main` branch and `/ (root)`, then save.
4. GitHub will show the published URL on the Pages settings screen after the first deployment.

Before publishing, replace the placeholder contact address (`your.email@university.edu`) and update the sample news items and any lab details that are not final.
